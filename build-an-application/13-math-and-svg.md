# 13. 数学とSVG

## 目的

描画を副作用のない文字列生成へ分解し、角度計算をテストします。実際のブラウザやファイルを使わず、SVGの属性を観測可能な出力として扱います。

## Red → Green → Refactor

3時30分の時針105度、分針180度という例をテストします。12時を超える入力の正規化も境界値として追加します。

完成実装は [`render_clock_svg`](../src/lib.rs)です。次はSVG要素を構造体へ分け、表示フォーマットの変更が計算ロジックに影響しない設計へ進めてください。

```bash
cargo test roman_and_clock_have_invariants
```
