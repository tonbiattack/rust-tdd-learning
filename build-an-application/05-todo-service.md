# 5. Todoサービス

## 目的

複数の振る舞いを持つ状態オブジェクトを、失敗時の状態も含めてテストします。`TodoList`は追加・完了・未完了一覧という小さなアプリケーションサービスです。

## 最初のテスト（Red）

空タイトルの追加、2件の追加、0番目の完了、存在しない番号の完了を一つのシナリオとして書きます。失敗後も件数が変わらないことを観測します。

## Green

状態は`Vec<Todo>`に保持し、追加時に空白だけのタイトルを拒否します。完了処理は`get_mut`と`Result`を用い、範囲外のインデックスをエラーにします。

## Refactor

`&mut self`が状態変更の境界であること、`pending_titles`が借用した文字列スライスを返すことを確認します。実装は [`src/lib.rs`](../src/lib.rs) の`TodoList`です。
