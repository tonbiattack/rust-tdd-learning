# 2. 整数と純粋関数

## 目的

`i32`の引数と戻り値を持つ純粋関数から、テストの最小単位を学びます。Rustの型検査は型の不一致を捕捉しますが、`+2`が意図どおりかはテストが仕様として固定します。

## Red → Green → Refactor

まず`add_two(-2) == 0`と`add_two(0) == 2`を書きます。最初の失敗から関数シグネチャを決め、最小実装を通します。最後にテスト名が「何を保証するか」を表していることを確認します。

完成実装は [`src/lib.rs`](../src/lib.rs) の`add_two`です。次は整数のオーバーフロー方針を決め、`checked_add`を使う版を設計してください。

```bash
cargo test add_two_covers_negative_and_zero
```
