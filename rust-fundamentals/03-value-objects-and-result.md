# 3. 値オブジェクトとResult

## 目的

`struct`で不変条件を閉じ込め、`Result<T, E>`で不正入力を明示的に扱います。ここではスコアを0〜100に限定し、60以上を合格とします。

## 最初のテスト（Red）

100、59、101の3ケースをテーブルとしてテストし、101を受け付けない失敗を確認します。

## Green

内部値を非公開の`u8`として保持し、`Score::new`だけが生成経路になるようにします。生成失敗は`ScoreError::OutOfRange`で返します。

## Refactor

`passed`が生の数値を各所に漏らさず、ドメインの言葉を表すメソッドになっていることを確認します。実装は [`src/lib.rs`](../src/lib.rs) の`Score`です。

## 次の一歩

合格基準を設定として注入する設計へ発展させ、テストがどの仕様に依存するかを考えてください。

```bash
cargo test score_enforces_range_and_pass_mark
```
